# รายงานผลการทดสอบการตัดทอนฟีเจอร์ (Phase 1 Feature Ablation Study): GBPUSD k=5

วันที่: 26 ต.ค. 2026 · ข้อมูล: Dukascopy M1 (2018–2026 รวม 3,282,666 แท่ง) · Payout: 85% (จุดคุ้มทุน 54.05%)

---

## 1. สรุปผลการทดลอง (Executive Summary)

การทดสอบนี้สร้างและประเมินฟีเจอร์กลุ่มใหม่ 4 กลุ่มบน `GBPUSD k=5` ผ่าน Purged Walk-Forward 6 Folds บนช่วงเวลาเดียวกันทั้งหมด (1 ม.ค. 2018 – 23 ต.ค. 2026) เพื่อวัดผลการยกระดับ (Lift) ทั้งแบบใส่เดี่ยวและจับคู่ รวม 11 การตั้งค่า

### ไฮไลท์สำคัญ:
1. **Volatility Squeeze & Vol Ratio (`+squeeze`) คือฟีเจอร์ที่เพิ่มความเสถียรสูงสุด:**
   - ดัน Win rate ขึ้นเป็น **54.93%** (เหนือจุดคุ้มทุน 54.05%)
   - ขยายจำนวนไม้เทรดจริงจากเดิม 346 ไม้ เป็น **1,500 ไม้** (เกือบ 5 เท่า) โดยรักษา EV เป็นบวก (+0.0163 ต่อเทรด)
   - มีค่า **PBO ต่ำมากเพียง 0.103** (เกณฑ์ Gate คือ $\le 0.20$) แสดงถึงความทนทานต่อ Overfitting อย่างโดดเด่น
2. **DXY + Cross-Asset (`+dxy+cross`) ให้ Win Rate สูงสุดที่ความมั่นใจสูง:**
   - เมื่อใช้คู่เงินอื่นและ Dollar Index ร่วมกันเพื่อกรองสัญญาณที่มีความมั่นใจสูง (Buffer 0.06) ได้ Win rate สูงถึง **65.96%** (EV +0.220 ต่อเทรด) แต่จำนวนไม้เทรดลดลงเหลือ 47 ไม้
3. **การจับคู่กับ Squeeze ให้ผลลัพธ์ Positive EV ทุกคู่:**
   - `+dxy+squeeze` (Win 54.53%, 1,821 ไม้)
   - `+cross+squeeze` (Win 54.59%, 1,438 ไม้)
   - `+squeeze+fracdiff` (Win 54.19%, 1,908 ไม้, PBO ต่ำสุด 0.044)

## 3. การวิเคราะห์เชิงปริมาณ (Quant Insights)

### 1. ความแตกต่างระหว่าง Vol Squeeze กับ DXY/Cross
* **DXY และ Cross-Asset:** ทำหน้าที่เป็น **Directional Macro Filter** เมื่อโมเดลเจอความสอดคล้องระหว่างคู่เงินและดอลลาร์ มันจะขยายความมั่นใจ ส่งผลให้เกิดไม้เทรดจำนวนมากที่ Buffer 0 (7,000–8,000 ไม้) แต่ Win rate เฉลี่ยอยู่ที่ ~53.1–53.6% ซึ่งโดน Noise ดูดกลืน อย่างไรก็ตาม หากตั้ง Buffer สูงที่ 0.06 สัญญาณที่รอดตัวกรองจะมีความแม่นยำสูงถึง **63–66%**
* **Vol Squeeze:** ทำหน้าที่เป็น **Regime / State Filter** โมเดลเรียนรู้ว่าช่วงที่ Bollinger Band บีบตัวต่ำกว่าปกติเมื่อเทียบกับ ATR (Squeeze state) เป็นช่วงที่การเคลื่อนที่หลังจากนั้นมีทิศทางชัดเจนขึ้น ช่วยคัดกรอง Noise ออกไปได้มากกว่า 80% และรักษา Win Rate ให้อยู่เหนือ 54.9%

### 2. ขอบล่าง Wilson (LCB) และบทเรียนเรื่องจุดคุ้มทุน
* แม้ `+dxy+cross` จะทำ Win Rate ได้ 65.96% แต่ด้วยจำนวนไม้เพียง 47 ไม้ ขอบล่าง 95% Wilson LCB จึงอยู่ที่ 54.00% (ปริ่มจุดคุ้มทุน 54.05%)
* ในขณะที่ `+squeeze` มีจำนวนไม้ 1,500 ไม้ Win Rate 54.93% ทำให้ได้ LCB 52.81%
* สิ่งนี้สะท้อนโครงสร้างเดิม: การเอาชนะกำแพง 54.05% ของ Binary Options ในระดับ 95% Statistical Certainty ยังคงตึงตัวมาก แต่ฟีเจอร์ชุดใหม่ทำให้เกิด **Positive EV Cluster** ที่แข็งแกร่งกว่าเดิมอย่างเห็นได้ชัด

## 4. ข้อเสนอแนะสำหรับ Phase 2 (โมเดลใหม่ 3 ตัว)

ผลจาก Phase 1 ชี้ชัดว่า **Feature Set ที่ดีที่สุด** มี 2 รูปแบบ:
1. **Balanced High-Volume Set (`+squeeze` หรือ `+dxy+squeeze`):** มี 27–32 ฟีเจอร์, ได้ 1,500–1,800 ไม้, Win rate 54.5–54.9%, PBO ต่ำ
2. **High-Precision Conviction Set (`+dxy+cross`):** มี 39 ฟีเจอร์, คัดเฉพาะไม้คมๆ Win rate 65%

ใน **Phase 2 (ทดสอบ 3 โมเดลใหม่: CatBoost, XGBoost, CNN+LSTM)** เราควรนำ Feature Set ที่มี Squeeze และ DXY/Cross ไปทดสอบกับสถาปัตยกรรมทั้ง 3 ตัวนี้เพื่อดูว่าโมเดลอย่าง CatBoost (ที่ถนัดเรื่องความสัมพันธ์ข้ามมิติ) หรือ CNN+LSTM (ที่ถนัดเรื่อง Sequence การบีบตัวของราคา) จะสามารถดันขอบล่าง LCB ให้ทะลุ 55%+ ได้หรือไม่
